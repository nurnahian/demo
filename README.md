# Spring Boot User Management API

A RESTful User Management API built with Spring Boot, PostgreSQL, Hibernate/JPA, Lombok, and Spring Security.

## Tech Stack

- Java 17
- Spring Boot
- Spring Data JPA / Hibernate
- PostgreSQL
- Spring Security
- Lombok
- Jakarta Validation
- Maven

## Features

- Create User
- Get All Users
- DTO-based API
- Request Validation
- Transaction Management
- Global Exception Handling
- Password Encryption
- Role Management
- PostgreSQL Integration
